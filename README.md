# Charfun

Charfun es un programa desarrollado en lenguaje Python cuya función principal se denomina `esPalindromo` y se encarga de comprobar si una cadena se lee de igual forma de izquierda a derecha y viceversa.

Este **programa está fuertemente orientado a la seguridad**. Por tanto, todo bug, fallo, mejora, comentario... Es bienvenido mediante el correo electrónico indicado más adelante.

## Teconologías utilizadas

- **Lenguaje**: Python (versión 3.13).
- **Librerías**: 
  - Unidecode: función `unidecode`.
  - Unittest: función `TesCase`.

## Modo de uso

1. Clona el repositorio: 

```bash
git clone https://github.com/fcuejur0712/PPS05.git
```

2. Sitúate en el directorio del proyecto:
```bash
cd PPS05/
```

3. Instala las dependencias:
```bash
pip install -r requirements.txt
```

4. Ejecuta el programa `main.py`:
```bash
python3 main.py
```
